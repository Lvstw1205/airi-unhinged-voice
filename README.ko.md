# AIRI Unhinged Voice

욕설과 거친 농담을 선택해서 사용할 수 있는 로컬 AI 목소리·말투 앱입니다.
처음에는 Calm으로 시작합니다. Unhinged 버튼을 누르면 욕설이 포함될 수 있습니다.
손님 모드는 언제든 부드러운 말투로 전환합니다.

1. Python 3.11 이상과 Ollama를 설치합니다.
2. Ollama를 실행하고 `ollama pull qwen3:4b`로 로컬 모델을 설치합니다.
3. ZIP을 풀고 `python3 run.py`를 실행합니다. Mac은 `Start.command`도 사용할 수 있습니다.
4. 브라우저에서 **http://127.0.0.1:8771**을 엽니다.
5. 모델과 목소리를 선택하고 메시지를 입력합니다. 자동 읽기는 직접 켜세요.

목소리 미리 듣기는 모델 없이도 사용할 수 있습니다. 목소리가 없으면 컴퓨터의 음성
설정에서 설치하세요. 이 프로젝트에는 개인 음성 파일이나 특정인의 목소리 복제가
포함되지 않습니다. 음성 입력이 아닌, 텍스트 대화와 음성 출력 앱입니다.

채팅은 서버 파일에 저장하지 않습니다. 현재 탭에 대화가 남고, 최근 12개 메시지만 로컬 모델에
맥락으로 전달됩니다. 새 대화 버튼으로 지울 수 있습니다.
말투 강도는 모델에 따라 다르며, 손님 모드의 비속어 필터가 모든 표현을 잡는 것은 아닙니다.

개인·비상업적 사용을 위한 공개 소스입니다. 자세한 조건은 LICENSE.md를 확인하세요.
