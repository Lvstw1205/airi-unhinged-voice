# Changelog

## 0.1.1 — 2026-10-07

Reject repetitive or unfinished model replies and retry once with more restrained sampling.
Tone changes cancel pending browser replies and stop speech; guest mode prevents replay of
earlier Unhinged replies. Prefer conversational models and exclude common embedding models.

## 0.1.0 — 2026-10-07

First standalone community release: three opt-in tone levels, guest override, local Ollama
chat, installed voice selection, preview/playback controls and a reusable Python persona layer.
