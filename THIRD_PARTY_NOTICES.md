# Third-party notices

The application uses the Python standard library and browser SpeechSynthesis APIs.
Ollama, downloaded language models, browsers and installed OS voices are separate products
with their own licenses. This repository does not redistribute their weights or audio.

The reusable tone behavior was adapted from AIRI's owner-selected banter/guest-mode concept;
public prompts and examples are newly written and contain no private conversation history.
The loopback HTTP boundary is shared with the AIRI community projects by the same author.
